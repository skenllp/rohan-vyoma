# Rohan & Vyoma – Static Invitation (HTML/CSS/JS)
No build step. Open via any static server (e.g. `npx serve .`) or deploy the folder to Vercel/Netlify/GitHub Pages.
- Edit all content in the `CFG` object at the top of `script.js`.
- OG/Twitter URLs are set to https://rohan-vyoma.vercel.app/ (change in `index.html` if the domain changes).
- Music: `assets/bansuri.mp3` is a synthesized original bansuri-style loop (Yaman + tanpura). Replace it with any licensed recording of the same name.
- Fonts load from Google Fonts.
