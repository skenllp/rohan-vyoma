# Rohan & Vyoma – Static Invitation (HTML/CSS/JS)
No build step. Open via any static server (e.g. `npx serve .`) or deploy the folder to Vercel/Netlify/GitHub Pages.
- Edit all content in the `CFG` object at the top of `script.js`.
- Replace `SITE_URL` in `index.html` (OG/Twitter tags) with your final domain.
- Music: add `assets/bansuri.mp3`; the player appears only if the file exists.
- Fonts load from Google Fonts.
